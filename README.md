# ⛽ GasPro


Sistema de Tienda Online y Administración

---

# 📋 Objetivos del Proyecto

- Desarrollar una tienda online básica.
- Implementar navegación entre múltiples páginas.
- Aplicar estilos personalizados mediante CSS.
- Implementar validaciones de formularios con JavaScript.
- Gestionar productos mediante arreglos y LocalStorage.
- Utilizar GitHub como sistema de control de versiones.

---

# 🛠 Tecnologías Utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Git
- GitHub

---

# 🚀 Funcionalidades Implementadas

## Tienda Online

### 🏠 Home
- Presentación de la empresa.
- Navegación principal.
- Productos destacados.
- Acceso al carrito de compras.

### 📦 Productos
- Listado dinámico de productos.
- Filtro por categorías.
- Detalle de producto.
- Agregar al carrito.

### 🛒 Carrito de Compras
- Agregar productos.
- Modificar cantidades.
- Eliminar productos.
- Calcular total.
- Persistencia mediante LocalStorage.

### 📰 Blogs
- Noticias de la empresa.
- Consejos de seguridad.
- Información para clientes.

### 📧 Contacto
- Formulario de contacto.
- Validación de campos.
- Restricción de correos autorizados.

# ✔ Validaciones

## Login

### Correo
- Obligatorio.
- Máximo 100 caracteres.
- Dominios permitidos:
  - @duoc.cl
  - @profesor.duoc.cl
  - @gmail.com

### Contraseña
- Entre 4 y 10 caracteres.

## Usuarios

### RUN
- Entre 7 y 9 caracteres.
- Sin puntos ni guión.
- Validación de RUN chileno.

### Nombre
- Máximo 50 caracteres.

### Apellidos
- Máximo 100 caracteres.

### Dirección
- Máximo 300 caracteres.

## Productos

### Código
- Mínimo 3 caracteres.

### Precio
- Mínimo 0.
- Acepta decimales.

### Stock
- Solo números enteros.
- Mínimo 0.
